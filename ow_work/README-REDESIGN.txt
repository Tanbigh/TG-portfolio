TANBI GHOSH — PORTFOLIO REDESIGN

This is a static HTML/CSS/JavaScript portfolio.

HOW TO PREVIEW
1. Extract the ZIP folder.
2. Open index.html in Chrome, or open the folder in VS Code and use Live Server.
3. Keep the assets folder beside index.html. Do not rename the image, PDF, or audio files unless you also update their paths in index.html.

DEPLOYMENT
Upload the complete folder contents to your existing static hosting provider (for example, Vercel or GitHub Pages).

NOTES
